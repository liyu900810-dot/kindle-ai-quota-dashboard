# 隐私模式

## 局域网模式

页面只在家庭或办公室网络中提供，数据不上传到公共托管。优点是隐私更强；缺点是 Kindle 离开该网络后不能更新。

## 公共静态页面模式

适合 Kindle 在不同 Wi‑Fi 之间移动。任何写入页面的数据都应视为公开信息，包括：

- AI 服务使用比例和余额；
- 更新时间与使用节奏；
- 天气、城市或更精确的位置；
- 每日一语及其署名。

不要把令牌写进快照。不要依赖“网址很难猜”保护隐私。

## 建议

- 公开部署默认关闭天气与地点。
- 示例截图只用 `npm run demo` 产生的数据。
- 若需要公开演示和私人使用并存，使用两个完全独立的部署仓库。
